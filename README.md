# Calculator With History

A simple Calculator application built using Python. The calculator performs basic arithmetic operations and stores calculation history for future reference.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- View calculation history
- Save calculation records

## Technologies Used

- Python
- Functions
- File Handling
- Conditional Statements
- Loops
